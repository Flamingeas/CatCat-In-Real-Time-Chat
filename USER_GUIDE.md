# Guide utilisateur / User Guide

---

## Français

### 1. Compte

| Action | Comment |
|---|---|
| **S'inscrire / Se connecter** | Page d'accueil → bouton « Se connecter / S'inscrire » |
| **Modifier son profil** | Icône en bas à gauche → Paramètres du compte (username, email, mot de passe, thème, langue) |
| **Se déconnecter** | Menu → « Se déconnecter » |

---

### 2. Serveurs

| Action | Comment |
|---|---|
| **Créer un serveur** | Barre gauche → bouton **+** → « Créer un serveur » |
| **Rejoindre un serveur** | Barre gauche → **+** → « Rejoindre un serveur » → coller le code d'invitation (8 caractères) |
| **Inviter quelqu'un** | Sélectionner le serveur → icône d'invitation → copier le code et le partager |
| **Paramètres du serveur** | En-tête du serveur → « Paramètres du serveur » (renommer, supprimer) |
| **Quitter un serveur** | En-tête du serveur → « Quitter le serveur » |

---

### 3. Channels

| Action | Comment |
|---|---|
| **Créer un channel** | Panneau gauche → **+** à côté de « Channels » *(owner/admin uniquement)* |
| **Renommer / Supprimer** | Clic droit sur le channel → Renommer ou Supprimer *(owner/admin uniquement)* |
| **Ecrire dans un channel** | Cliquer sur un channel → zone de saisie en bas |

---

### 4. Messages

| Action | Comment |
|---|---|
| **Envoyer** | Taper dans la zone de saisie → Entrée |
| **Envoyer un GIF** | Icône GIF dans la barre de saisie → chercher et cliquer |
| **Modifier** | Survoler le message → Modifier |
| **Supprimer** | Survoler le message → Supprimer |
| **Réagir (emoji)** | Survoler le message → « + réaction » → choisir un emoji |
| **Mentionner** | Taper `@username` dans le message |

---

### 5. Messages directs

| Action | Comment |
|---|---|
| **Ouvrir les DMs** | Icône en haut de la barre gauche → « Messages directs » |
| **Nouvelle conversation** | Bouton **+** dans la liste des conversations |
| **Envoyer / Modifier / Supprimer** | Identique aux messages de channel |

---

### 6. Membres & Modération *(owner/admin)*

| Action | Comment |
|---|---|
| **Voir les membres** | Colonne droite du serveur |
| **Rôles** | Clic sur un membre → Rendre admin / Retirer admin / Transférer ownership |
| **Kick** | Clic sur un membre → Expulser |
| **Ban permanent** | Clic sur un membre → Bannir définitivement |
| **Ban temporaire** | Clic sur un membre → Bannir temporairement → choisir la durée (5 min → 7 jours) |
| **Débannir** | Panneau membres → « Utilisateurs bannis » → Retirer le ban |

---

### 7. Présence & Notifications

- Les membres **en ligne / hors ligne** apparaissent en temps réel dans la colonne droite.
- Les indicateurs de **frappe en cours** s'affichent sous la liste des messages.
- Les **notifications système** arrivent pour les nouveaux DMs et les mentions `@`.

---

### 8. Interface

| Option | Où |
|---|---|
| **Thème** clair / sombre | Paramètres du compte |
| **Langue** FR / EN | Paramètres du compte ou sélecteur en haut de page |

## English

### 1. Account

| Action | How |
|---|---|
| **Sign up / Sign in** | Home page → « Sign in / Sign up » button |
| **Edit profile** | Icon bottom-left → Account Settings (username, email, password, theme, language) |
| **Log out** | Menu → « Log out » |

---

### 2. Servers

| Action | How |
|---|---|
| **Create a server** | Left bar → **+** button → « Create a server » |
| **Join a server** | Left bar → **+** → « Join a server » → paste the 8-character invite code |
| **Invite someone** | Select the server → invite icon → copy & share the code |
| **Server settings** | Server header → « Server settings » (rename, delete) |
| **Leave a server** | Server header → « Leave the server » |

---

### 3. Channels

| Action | How |
|---|---|
| **Create a channel** | Left panel → **+** next to « Channels » *(owner/admin only)* |
| **Rename / Delete** | Right-click the channel → Rename or Delete *(owner/admin only)* |
| **Write in a channel** | Click a channel → type in the input bar at the bottom |

---

### 4. Messages

| Action | How |
|---|---|
| **Send** | Type in the input bar → Enter |
| **Send a GIF** | GIF icon in the input bar → search and click |
| **Edit** | Hover a message → Edit |
| **Delete** | Hover a message → Delete |
| **React (emoji)** | Hover a message → « + reaction » → pick an emoji |
| **Mention someone** | Type `@username` in the message |

---

### 5. Direct Messages

| Action | How |
|---|---|
| **Open DMs** | Top icon in the left bar → « Direct messages » |
| **New conversation** | **+** button in the conversation list |
| **Send / Edit / Delete** | Same as channel messages |

---

### 6. Members & Moderation *(owner/admin)*

| Action | How |
|---|---|
| **View members** | Right column of the server |
| **Roles** | Click a member → Make admin / Remove admin / Transfer ownership |
| **Kick** | Click a member → Kick |
| **Permanent ban** | Click a member → Permanently ban |
| **Temporary ban** | Click a member → Temporarily ban → choose duration (5 min → 7 days) |
| **Unban** | Members panel → « Banned users » → Remove ban |

---

### 7. Presence & Notifications

- Members show as **online / offline** in real time in the right column.
- **Typing indicators** appear below the message list.
- **System notifications** are sent for new DMs and `@` mentions.

---

### 8. Interface

| Option | Where |
|---|---|
| **Theme** light / dark | Account Settings |
| **Language** FR / EN | Account Settings or the switcher at the top of the page |
